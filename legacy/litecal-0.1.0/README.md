# LiteCal 0.1.0 historical source

This directory contains the modular source from the repository's original
LiteCal 0.1.0 commit. It is preserved to help restore clean module and Vue SFC
boundaries, but it is not the current TimeMaster V2 implementation and is not
used by the root build.

The current source-equivalent 0.1.3 build lives in `../../src/`.
